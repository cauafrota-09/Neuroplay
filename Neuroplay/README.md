# Neuroplay

Firmware em C++ para controle do hardware do projeto Neuroplay.

## 📌 Visão Geral
Sistema embarcado desenvolvido para gerenciar interações e lógica principal do dispositivo.

## 🔌 Pinout / Conexões
| Componente | Pino Microcontrolador | Descrição |
| :--- | :--- | :--- |
| Botão Start | `A0` (ou defina seu pino) | Entrada de acionamento do jogo/sistema |

## 🚀 Como Compilar / Enviar
1. Abra o arquivo `Neuroplay.cpp` (ou renomeie para `.ino` se for usar a IDE clássica do Arduino).
2. Seleciona a placa correta.
3. Faça o upload para a placa.

## 🛠️ Tecnologias
* C++ / Arduino Framework
